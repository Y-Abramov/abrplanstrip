# ABR | CIVIL - Развёртка плана

Спрямляет ситуационный план вдоль трассы и кладёт его блоком над сеткой
продольного профиля, с сохранённой в чертеже моделью для пересчёта.

## Команды

| Команда | Действие |
|---------|----------|
| `PLANSTRIP` | Построить полосу через диалог |
| `PLANSTRIPUPDATE` | Пересчитать полосу (без выбора - все полосы чертежа) |
| `PLANSTRIPERASE` | Удалить полосу: вставку, определение блока, запись в чертеже |
| `PLANSTRIPSETTINGS` | Сохранить текущие настройки диалога как именованный пресет |
| `PLANSTRIPABOUT` | О модуле |

## Известные ограничения v1

- Шаг горизонталей поверхности фиксирован (1 м), в диалоге не настраивается.
- Ширина полосы одна на всю трассу - переменной ширины по пикетажу нет.
- В режиме «по углам» на стыках кусков возможны клинья и нахлёсты геометрии -
  это ожидаемо для жёсткого посегментного переноса, не баг.
- Текст меток Civil-объектов (`*LabelGroup`) не читается: живая разведка (Task 2)
  не нашла способ вытащить текст/точку/поворот метки из API - Explode отдаёт только
  прокси-графику без текста. Метка попадёт в полосу как пустой маркер на своём месте.
